使用本平台的服务及功能，您必须阅读并遵守[《哔哩哔哩创作者开放平台管理规范》](https://open-live.bilibili.com/document/f6017467-1182-fd2b-7a96-793b9afb911a)[《哔哩哔哩创作者开放平台服务协议》](https://open-live.bilibili.com/agreement)、[《哔哩哔哩创作者开放平台信用分管理规范》](https://open-live.bilibili.com/document/5253757c-00a5-83e8-19ed-107d95fca355)以及哔哩哔哩为此制定的专项规则等。本规范是在上述协议及规则基础上进行解释和说明，相关内容旨在帮助您更加清晰地理解和遵守相关协议和规则，以便能够更加顺利地在本平台进行项目的提交及运营，而不是修改或变更上述协议及规则中的任何条款。如果我们认为您在使用本平台服务中违反了我们的条款、相关规则或法律法规，或对哔哩哔哩造成了影响，则哔哩哔哩有权对您的平台项目采取强制措施，包括但不限于限制您的项目访问本平台功能、封禁项目、删除数据、终止服务协议等。
### 订阅扩展（DLC）内容提交规范
#### 1.基础信息
##### 1.1.内容资质
1.1.1.上传订阅扩展内容的公司如与软著的公司主体为子母公司、分公司，请提交真实有效的证明。
1.1.2.上传订阅扩展内容的公司如与软著的公司存在授权关系，请提交完整、真实、可追溯的授权链证明。
1.1.3.订阅扩展内容的开发、运营者应当符合法律、法规等规范性文件的规定，任何有合理理由认为存在违反法律、法规或监管要求的情况的，将会被拒绝。
1.1.4.您应当按照我们的要求提供相应的审批、备案等资质文件材料，否则，我们有理由相信您提交的订阅扩展内容存在违反法律、法规或监管要求的情况。您所提交的资质文件材料，均应为真实、合法、有效的。哔哩哔哩创作者开放平台将在合法权限和能力范围内对您的订阅扩展内容进行发布审核，如我们发现您提交的文件材料存在任何伪造、造假情况，我们有权对拒绝您的订阅扩展内容或对其采取强制措施，并保留追究您相应的法律责任的权利。
1.1.5.未取得法定许可证件或牌照，发布、传播或从事相关经营活动的，我们有权拒绝。
1.1.6.任何有合理理由认为从事或为从事违法行为、非法活动提供便利、协助的，将会被拒绝。
##### 1.2.运营和 IP 授权
1.2.1.订阅扩展内容为运营代理，请提交完整、真实、可追溯的独家授权链证明。
1.2.2.订阅扩展内容素材、音乐等内容涉及相关 IP ，需提交完整、真实、可追溯的授权链证明。
1.2.3.IP 权利人若为上传订阅扩展内容的公司/个人所有，需提交真实有效的证明。
1.2.4.IP 授权范围必须与上传订阅扩展内容的内容吻合，且真实有效。
##### 1.3.素材授权
1.3.1.素材不得使用版权敏感内容，包括但不限于网络素材、同人素材。
1.3.2.素材若有真人形象，需提交肖像使用授权书。
1.3.3.素材若为原创素材，需提交真实有效的证明。
1.3.4.使用素材若为购买的商业素材，需提交素材购买页面和订单证明
##### 1.4.软著
1.4.1. 玩法开发者需提供软件著作权登记号以及登记证书扫描件（ 必须为 JPG 或 PNG 格式 ），如果提交玩法订阅扩展内容的厂商非该软著著作权人，需提供相应软著授权，请务必保证授权链独家且完整。
1.4.2.如版号有更名、转移主体等历史，请务必提交完整的扫描件材料（ 拼接为同一张，必须为 JPG 或 PNG 格式 ）。
##### 1.5.ICP备案
1.5.1. 插件开发者需提供icp备案号与相关身份扫描件（个人：身份证，企业：营业执照，主体负责人信息）（ 必须为 JPG 或 PNG 格式 ），且需要icp备案主体与开发者提供信息对应
1.5.2.如ICP备案转移主体等历史，请务必提交完整的扫描件材料（ 拼接为同一张，必须为 JPG 或 PNG 格式 ）。
### 订阅扩展（DLC）内容审核细则
#### 1.内容规范细则
##### 1.1.标题规范
1.1.1.标题中不得添加违反平台规定的信息。
1.1.2.标题中不得添加误导用户、与订阅扩展内容无关的信息。
1.1.3.标题中不得添加地区信息。
##### 1.2.简介规范
1.2.1.描述不得与订阅扩展内容无关。
1.2.2.描述不得添加时效性内容，如X月X日。
1.2.3.描述不得添加商业化用语，如免费送XXX等。
1.2.4. 描述不得添加该订阅扩展内容所有平台和媒体评价。
1.2.5.描述不得添加大量占位符文本、空格、乱码等非法字符，如：.、#、*、& 等。
1.2.6.描述不得添加未获得授权的ip内容，如电影改编、真实人名、其他游戏等。
1.2.7.描述不得添加恶俗，玩梗等内容。
1.2.8.描述不得只重复填写订阅扩展内容标题而不含其他内容。
1.2.9.描述不得添加极限词等绝对化用语，包括但不限于“最”、“首/家/国”、“一”及相关词语。
1.2.10.描述不得添加迷信用语，如提升运气、增加事业运、招财进宝等。
1.2.11.描述不得添加虚构的统计数据，如1亿主播都在玩的功能、耗资X亿开发等。
1.2.12.描述不得添加打色情擦边球的用语，如零距离接触、余温、余香、身体器官描述等违背社会良好风尚的色情暗示词语。
1.2.13.描述不得添加虚假内容相关词语，如史无前例、前无古人、永久等无法提供证明的虚假宣传词语。
1.2.14.描述不得添加激发玩家下载或者购买心理的表述，如秒杀、抢爆、史上最低价、免费领等。
1.2.15.描述不得添加不利于未成年人身心健康的内容
##### 1.3.物料审核
1.3.1.图片及视频素材必须保证清晰，不得出现明显模糊、拉伸、压缩、黑边、白边等情况，不得使用纯色、渐变等过于简单图案。
1.3.2.图片及视频不得违反基本法律法规，需符合基本要求。
1.3.3.图片及视频中不得含有违反平台收录标准的内容，包括但不限于提现、实质性奖励信息内容及相关素材。
1.3.4.图片及视频中不得含有与游戏内容无关的素材，包括但不限于其他游戏或应用广告、厂商联系方式。
1.3.5.图片及视频中不得含有侵权内容，已获授权素材或购买素材需上传相应证明材料或授权书。
1.3.6.图片及视频中不得含有与订阅扩展内容无关信息。
1.3.7.图片及视频中不得添加强制引导信息。
1.3.8.图片及视频中不得添加引导至其他网站的信息；
#### 2.功能审核规范
##### 2.1.功能显示
2.1.1.所有页面标题、正文、图文信息等通俗易懂，未含有敏感和违规信息。
2.1.2.图片不可出现尺寸异常、比例变形、模糊等情况。
2.1.3.无图片、加载失败时，需要有默认图片占位。
2.1.4.订阅扩展内容里面的图片，不能包含广告、网址。
2.1.5.弹框提示文案保持页面居中（垂直&水平）文字不宜过多，建议不超过 12 个汉字。
2.1.6.不能出现引导用户下载的文案及链接。
2.1.7.不可出现白屏页面。
2.1.8.敏感信息需脱敏显示（身份证、真实姓名、电话、邮箱等）。
2.1.9.订阅扩展内容页面内的浮层和弹窗可关闭。
2.1.10.如相关法律法规规定提供服务的界面必须进行特别信息标识的，应予以明确标识
2.1.11.订阅扩展内容页面不应该出现日志，调试之类的
##### 2.2.可用性
2.2.1.提交的订阅扩展内容须是一个完成品，要求可以打开，可以运行
2.2.2.订阅扩展内容中禁止全英文和复杂英文
2.2.3.声明的功能模块必须要实现
2.2.4.进入订阅扩展内容多级页面均需有返回方式
##### 2.3.稳定性
2.3.1.订阅扩展内容本身不存在崩溃、闪退等情况
2.3.2.订阅扩展内容不能存在严重 Bug 
2.3.3.订阅扩展内容出现网络异常、加载超时、系统错误等情况时需给予用户相应提示，不可出现黑屏等其他错误
##### 2.4.接口
2.4.1.订阅扩展内容接口问题，对接开放平台产品需遵循该产品接口接入规范，使用订阅扩展内容 API 接口功能，需确保各个 API 接口调用功能正确
