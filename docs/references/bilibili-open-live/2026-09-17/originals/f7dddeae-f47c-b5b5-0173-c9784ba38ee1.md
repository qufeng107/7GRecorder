# 订阅记录查询

<font size=5 color=Red>&nbsp;&nbsp;&nbsp;&nbsp;该文档中提到的订阅记录查询接口，仅提供用于订阅流程结束，事后回查订单。 </font>
<font size=5 color=Red>&nbsp;&nbsp;&nbsp;&nbsp;出于流程和时效性的原因，请勿嵌入订阅流程中。 </font>

## 请求URL

https://api.live.bilibili.com/xlive/open-platform/v1/appDlc/queryOrderList

## 接口说明

开发者可以根据dlc_id和order_id订单号列表，查询dlc订单状态

## 通讯方向

开发者服务器调用开放平台服务器

## 请求方式

POST

## 请求头

Content-Type: application/json

统一鉴权文档 公共请求头，详见https://open-live.bilibili.com/document/74eec767-e594-7ddd-6aba-257e8317c05d

## 请求参数

| 参数名    | 必传 | 类型       | 备注                                                         |
| --------- | ---- | ---------- | ------------------------------------------------------------ |
| dlc_id    | true | string     | 订阅拓展(DLC) id                                             |
| order_ids | true | string数组(list<string>) | 订单id号列表,最多200个.超过200会提示参数错误,支持查询dlc上架/下架,有购买记录的订单id. |

## 请求样例

```
{
    "dlc_id":"000000abc-1234-abcd-1234-12345aa67890",
    "order_ids": ["123451234567890123456789","123451234567890123456788"],
}
```

## 响应参数

order_list列表，具体参数如下：

- body参数

| 参数名                       | 必传 | 类型    | 备注                                                         |
| ---------------------------- | ---- | ------- | ------------------------------------------------------------ |
| order_list.dlc_id            | true | string  | 订阅拓展(DLC) id                                             |
| order_list.order_id          | true | string  | 订单id号                                                     |
| order_list.order_status      | true | integer | 1代表进行中,2代表成功,3代表失败已退款              |
| order_list.order_create_time | true | integer | 订单发生时间戳                                               |
| order_list.order_finish_time | true | integer | 订单完成时间戳,完成场景包括用户收到dlc商品,发货失败触发退款。 |
| order_list                   | true | list    | 订单列表                                                     |

```
    "code": 0,
    "message": "0",
    "request_id": "1776868026705784832",
    "data": {
         //  订单列表
        "order_list": [

                "order_id": "123451234567890123456789",
                //  dlc id

                //  订单状态 1代表进行中,2代表成功,3代表失败已退款
                "order_status": 2,

                //  订单成功/失败状态时间戳

            }
        ]
    }

```

## 错误码

| 错误码 | 含义                             | 说明                                  |
| ------ | -------------------------------- | ------------------------------------- |
| 60001  | 查询订单列表有失败结果           | 订单id列表全部/部分查询失败           |
| 60002  | dlc_id错误                       | Accesskey对应开发者名下没有对应dlc_id |
| 60003  | 查询数量超过上限                 | 订单列表查询超过200上限               |
