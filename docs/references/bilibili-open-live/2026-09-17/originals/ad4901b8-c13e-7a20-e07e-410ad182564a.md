# H5插件API

<font color=Red>警告</font>
出于安全性考虑，H5插件会通过iframe嵌入容器页面的形式访问，为了保证容器对H5插件的正常访问，请在服务器的Response Headers中添加以下字段：  
X-Frame-Options: ALLOW-FROM https://play-live.bilibili.com/


## 接入流程

<font color=Red>提示</font>
发布的url必须通过使用https的域名访问。


![H5插件接入流程图](https://i0.hdslb.com/bfs/activity-plat/static/20230506/cc51945399520f91bb65629803b43743/plugImg.png)

<font color=Red>注意</font>
插件有两次身份验证。 第一次为插件验证应用商店的身份，应用商店会把签名带给插件，插件按要求对签名进行验签；  
当插件启动后，需要调用开放平台插件开启的接口，此时需要按照[鉴权页](/doc&tool/auth.html)的签名要求对数据进行签名，然后再调用接口，此时为开放平台验证插件的身份。


## H5插件场景参数

`plug_env=1`显示设置项区域的场景，如插件详情页、直播姬内插件配置弹窗。

![plug_env=1](https://i0.hdslb.com/bfs/activity-plat/static/20230506/cc51945399520f91bb65629803b43743/plugenv1.png)

`plug_env=0`插件实际使用的场景，如插件详情页复制链接、直播姬内使用载入的链接。

![plug_env=0](https://i0.hdslb.com/bfs/activity-plat/static/20230506/cc51945399520f91bb65629803b43743/plugenv0.png)

## 验证应用商店签名-Sign生成流程

<font color=Red>注意</font>
不验证签名存在风险，请注意！

### 新版签名
#### 1. 将Sign生成字段进行ASCII码值升序排序

插件鉴权需要使用到 Timestamp、Code、Mid、Caller 字段，其ASCII码值升序排序为: Caller、Code、Mid、Timestamp。
其中code为用户身份码
mid为主播uid
#### 2. 将排序后的字段及其值拼接为一个完整的字符串(加密数据)

拼接格式：`{sign_key}:{sign_value}\n`  
sign_key之间使用`\n`作为分隔符  
如将以上字段进行拼接示例为：
```
Caller:bilibili
Code:Code_value
Mid:Mid_value
Timestamp:Timestamp_value
```

#### 3. 使用HmacSHA256算法，将加密数据与秘钥生成Sign

示例：
```
// 加密数据:
Caller:bilibili
Code:Code_value
Mid:Mid_value
Timestamp:Timestamp_value
// 秘钥:
b613679a0814d9ec77
// 生成CodeSign:
3345157f6b50376c42001e814b101f8afc2f335d46319729f96ec78af5118516
```

#### 【php签名示例代码】
```php
<?php
//Timestamp=1650012983&Code=460803&Mid=110000345&Caller=bilibili&CodeSign=8c1fa83955d83960680277122bd31fd6f209a82787d57912c1d3817487bfc2ef
 $arr = array(
 	"Timestamp" => "1650012983",
 	"Code" => "460803",
	"Mid" => "110000345",
	"Caller" =>"bilibili");

$secret = "NPRZADNURSKNGYDFMDKJOOTLQMGDHL";
echo sign($arr, $secret);
// output 8c1fa83955d83960680277122bd31fd6f209a82787d57912c1d3817487bfc2ef
function sign($arr, $secret) {
 	ksort($arr);
 	$signData = "";
 	foreach ($arr as $key => $value) {
 		$signData .= $key . ":" . $value . "\n";
 	}
 	$signData = rtrim($signData, "\n");
 	return hash_hmac("sha256", $signData, $secret);
}
```

### 旧版签名（支持截止日期2022.06.30）

插件鉴权需要使用到 Timestamp、RoomId、Mid、Caller 字段，其ASCII码值升序排序为: Caller、Mid、RoomId、Timestamp。

#### 2.将排序后的字段及其值拼接为一个完整的字符串(加密数据)

拼接格式：`{sign_key}:{sign_value}\n`  
sign_key之间使用`\n`作为分隔符  
如将以上字段进行拼接示例为：
```
Caller:bilibili
Mid:Mid_value
RoomId:RoomId_value
Timestamp:Timestamp_value
```

#### 3.使用HmacSHA256算法，将加密数据与秘钥生成Sign

示例：
```

Mid:Mid_value

```
