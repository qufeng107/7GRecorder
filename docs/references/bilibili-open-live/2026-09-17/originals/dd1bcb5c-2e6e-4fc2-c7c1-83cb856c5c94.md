# 搜索媒体信息

- 需要应用单独权限

## 接口说明

- 使用关键字搜索音乐信息

## 接口地址

`/xlive/open-platform/v2/music/search`

## 请求方式

POST

## 请求头

对POST请求增加公共请求头（Request Header），详情请查看 [接口签名说明](https://open-live.bilibili.com/document/74eec767-e594-7ddd-6aba-257e8317c05d) 文档

## 请求参数

- url参数

无

- body参数

| 参数名      | 必传 | 类型 | 备注       |
| ----------- | ---- | ---- | ---------- |
| keyword | true | string  | 搜索关键词（歌曲、专辑、作曲等信息） |
| page | true | int  | 页数（从1开始计数） |
| page_size | true | int  | 每页条目数量 |
| code | true | int  | 主播身份码 |
| app_id | true | int  | 应用的app_id |

## 响应参数

- body参数

| 参数名      | 必传 | 类型 | 备注       |
| ----------- | ---- | ---- | ---------- |
| total | true | int  | 候选总数 |
| infos | true | List  | 满足条件的媒体列表 |

infos结构体如下：

| 参数名      | 必传 | 类型 | 备注       |
| ----------- | ---- | ---- | ---------- |
| metadata_id | true | string  | 资源的唯一ID |
| title | true | string  | 歌曲名 |
| artist_name | true | string  | 歌手名称 |

- 响应示例

```
{
    "code": 0,
    "message": "ok",
    "data": {
        "infos": [
            {
                "metadata_id": "",
                "title": "",
                "artist_name": ""
            }
        ],
        "total": 0
    }
}
```
