
# 哔哩哔哩创作者开放平台管理规范（细则）

## 一、原则及相关说明

　　哔哩哔哩团队一直致力于将哔哩哔哩打造成一个强大的、全方位的服务体系。在此基础上，我们推出了创作者开放平台（以下简称“本平台”）。
通过全面开放的能力，将更多连接的可能给予创作者，并为创作者开发的项目提供直播生态基础的接入能力、运营环境和规则体系，进而帮助更多的创作者建立自己的品牌，将商业机会带给整个哔哩哔哩直播产业链。

　　我们希望您提交的平台项目，能够符合哔哩哔哩团队一直以来的价值观，那就是：一切以用户价值为依归、让创造发挥价值、好的产品是用完即走，以及让商业化存在于无形之中。在切实符合用户的合理需求和利益的前提下，通过平台所提供的功能和服务，为海量哔哩哔哩用户提供具有持续价值和高品质的服务，我们期待您来提交您的作品！

## 二、具体创作规范
　　使用本平台的服务及功能，您必须阅读并遵守《哔哩哔哩创作者开放平台服务协议》、《哔哩哔哩创作者开放平台隐私政策》、《哔哩哔哩创作者开放平台信用分管理规范》以及哔哩哔哩为此制定的专项规则等。
  
　　本规范是在上述协议及规则基础上进行解释和说明，相关内容旨在帮助您更加清晰地理解和遵守相关协议和规则，以便能够更加顺利地在本平台进行项目的提交及运营，而不是修改或变更上述协议及规则中的任何条款。
  
　　如果我们认为您在使用本平台服务中违反了我们的条款、相关规则或法律法规，或对哔哩哔哩造成了影响，则哔哩哔哩有权对您的平台项目采取强制措施，包括但不限于限制您的项目访问本平台功能、封禁项目、删除数据、终止服务协议等。

### 1. 项目提交规范
1.1 您所提交的平台项目包括插件、互动玩法、直播工具三类（以下简称“平台项目”），不得关联至您不具有完整合法权益或不具备完整授权的网站、程序、产品或服务等。  
1.2 为保障本平台和其他用户的安全、稳定，我们会在您提交、运营平台项目等全过程中，要求您提供相应的材料、进行相应的修改等补充和调整，您应当按照我们的要求协助我们进行审核，否则将影响项目审核的结果。  
1.3 不允许批量注册、重复提交大量相似的平台项目。

### 2. 基本信息规范
您所填写的平台项目基本信息，需要能够准确描述该平台项目的功能和内容，能提供给用户直观的理解，符合用户对其实际提供的功能或服务的预期，避免引导、误导、混淆用户对该平台项目实际提供的功能或服务范围的理解。

2.1 平台项目的名称、logo和简介相互之间应存在关联，避免相互之间缺乏相关表达的联系，造成用户对该平台项目实际提供的功能或服务范围的混淆；  
2.2 不得含有政治敏感、色情、暴力血腥、恐怖内容及国家法律法规禁止的其他违法内容；  
2.3 不得混有商业化用语、热门公众号或平台项目名称、热门项目名称、流行用语、“国家级”、“最高级”等广告法律法规明令禁止的用语、水印标识等与平台项目功能或内容无关的内容；  
2.4 未经授权不得使用第三方享有合法权益的商标、品牌标识等内容或与之相似的内容、信息、特殊角标，侵犯他人合法知识产权，也不得含有其他侵犯他人合法权益（包括但不限于肖像权、名誉权、隐私权、姓名权等）的内容。例如：未授权情况下使用哔哩哔哩品牌，名称为“哔哩哔哩直播姬小助手”的平台项目，属于侵权行为。  
2.5 无正当理由，平台项目名称不能与已有平台项目或公众号、热门项目名称产生重复或混淆；不能使用广义归纳类、普遍且不具有识别性的词汇来命名，或在名称中包含热门搜索词及关键词堆砌，与搜索系统进行规则对抗，平台项目的命名应为品牌与产品描述或功能描述的结合。

### 3. 功能设置规范

3.1 平台项目所实际提供的服务和内容，需与其简介一致，且不存在隐藏类目。  
3.2 平台项目的核心功能，必须在平台项目首页得到体现。  
3.3 平台项目向用户提供基本的功能指引，应包括文字描述或图片、视频等形式。  
3.4 平台项目的服务范围需与实际填写的类目和标签一致，也需和自身所提供的服务一致，且不应超出平台项目的类目范围。  
3.5 平台项目的功能不能过于简单，提供的功能不应与平台已拥有的功能、其他哔哩哔哩已有功能同质化严重。  
3.6 平台项目的创建及上架是免费的，未经哔哩哔哩授权的情况下，付费添加和收取服务费应向哔哩哔哩提出申请。  
3.7 未经哔哩哔哩授权的情况下，不得提供与哔哩哔哩客户端功能相同或者相似的功能。  
3.8 未经允许或未经哔哩哔哩授权的情况下，平台项目功能的使用，不得依赖于其他平台项目，即不得以使用其他平台项目为条件，也不得依赖于其他项目程序；未经允许或未经哔哩哔哩授权的情况下，也不得展示或者推荐其他平台项目或第三方公众号。  
3.9 应完善客服与设置侵权投诉机制，处理与主播、用户间的权益纠纷。  
3.10 应按照国家法律、法规等政策的规定，及相关操作终端设备系统、项目商店或市场的要求，对可能涉及不宜未成年人接触的内容或服务予以提醒或处理，保护未成年人的身心健康和合法权益。  
3.11 平台项目内容或功能不得纯粹或主要用于将女性或男性的外貌、身份、特定或综合的个人能力等等进行商品化展示，并以此作为引导或推广。如纯粹的美女图册、视频集、图文集等。

### 4. 主体规范

4.1 平台项目的开发、运营者应当符合法律、法规等规范性文件的规定，任何有合理理由认为存在违反法律、法规或监管要求的情况的，将会被拒绝。  
4.2 哔哩哔哩将在合法权限和能力范围内对您的平台项目进行审核和管理，如我们发现您提交的文件材料存在任何伪造、造假情况，我们有权拒绝您提交的平台项目或对其采取强制措施，并保留追究您相应的法律责任的权利。  
4.3 任何有合理理由认为从事或为从事违法行为、非法活动提供便利、协助的，将会被拒绝并追究责任。

### 5. 内嵌网页规范
5.1 创作者在平台项目内嵌的网页必须已经履行备案手续；  
5.2 创作者通过平台项目内嵌网页所提供的服务，必须与哔哩哔哩平台项目填写的类目和标签一致，也需和自身所提供的服务一致，且不应超出平台项目平台的类目库范围；  
5.3 创作者在平台项目内嵌的网页内容，需遵守《哔哩哔哩隐私政策》的规定， 不得发布、传送、传播国家法律法规禁止的和违反平台规则的信息；  
5.4 创作者在平台项目内，不得通过提供内嵌网页的方式，绕开或规避平台规则；  
5.5 一旦发现创作者存在违反本条规范的行为，哔哩哔哩有权对其进行限制功能直至封禁处理，并有权拒绝再向该主体提供服务。

### 6. 商标与商业外观
6.1 平台项目必须遵守商标、版权等知识产权法律法规以及哔哩哔哩关于知识产权使用的相关规则。  
6.2 使用他人商标、版权内容等涉及他人知识产权的内容需要在平台项目提交审核申请时如实说明，并根据要求提供相关权利证书或授权证明等。非权利人或未经授权的，不得使用他人享有合法知识产权的内容。  
6.3 非哔哩哔哩官方帐号，禁止在帐号名称、输出内容中出现与哔哩哔哩已有知识产权内容相同、相近似的字样，或者容易与目前已有哔哩哔哩产品设计主题、外观等相混淆的内容。  
6.4 非哔哩哔哩实际运营的平台项目，不得误导和暗示用户哔哩哔哩是该平台项目运营者，或者误导和暗示用户哔哩哔哩以任何形式表示认可其质量、服务或与其存在合作关系。

### 7. 可用性和完整性规范
7.1 提交审核上架的平台项目应该是一个完成品，要求可以打开、运行或使用，且不得为测试版。  
7.2 平台项目程序不应造成哔哩哔哩各客户端崩溃或程序本身崩溃。  
7.3 不应存在严重Bug（如无法添加和打开、无法返回和退出、卡顿严重等）。  
7.4 创作者应保证已发布平台项目的使用流畅性、稳定性和安全性，若因平台项目自身原因导致其向用户提供的服务中断且未能在哔哩哔哩认为的合理期限内修复的，哔哩哔哩有权采取包括但不限于临时下架或封禁等处理措施，以维护良好的用户体验。  


### 8. 技术实现规范

8.1 遵守《哔哩哔哩创作者开放平台开发文档》中的技术规范和规则约定。  
8.2 平台项目创作者允许并授权哔哩哔哩团队对提交的代码进行漏洞安全测试。  

**8.3 系统安全要求**  
- 8.3.1 严禁利用手机系统、哔哩哔哩或其他软件或硬件的技术漏洞，一旦发现将回收平台项目创作者的帐号资格。
- 8.3.2 不得安装或运行其他可执行代码的程序。
- 8.3.3 不得利用平台项目传播病毒。  

**8.4 API 的使用**  
- 8.4.1 不得使用非公开的API的程序。
- 8.4.2 使用内测中的API的程序，哔哩哔哩团队有权保留回收接口的权利。
- 8.4.3 禁止违规（跨主体）使用其他第三方项目的API。
- 8.4.4 未经哔哩哔哩允许，不得将我们的代码、API或工具出售、转让或转授给他人。
- 8.4.5 不得对任何SDK或组件进行修改、转译或进行逆向工程，也不得将其用之于制作衍生产品。  

**8.5 其它要求**  
- 8.5.1 执行多任务时，使用后台服务仅限于几种目的：VoIP、音频播放、地理位置、完成任务以及本地提醒等。
- 8.5.2 不得改变原生用户界面元素和行为（如音量增减和静音开关或其他）。
- 8.5.3 禁止视频、音乐、语音等多媒体的自动播放。
- 8.5.4 不得在用户不知情的情况下，使用录音功能。

### 9. 平台项目设计规范
9.1 应符合哔哩哔哩平台项目相关的设计规范。  
9.2 维护哔哩哔哩的外观和功能，不得提供改变哔哩哔哩外观和功能的用户体验。  
9.3 保持所有图片文本简洁，不可使用文本遮挡图片。  
9.4 icon建议使用有色背景。  
9.5 平台项目页面内的浮层和弹窗应可关闭。  
9.6 不得模仿系统通知或警告诱导用户点击。

### 10. 插件/直播工具类规范
10.1 创作者提供的插件/直播工具，必须符合法律、法规或相关规章的规定，创作者不得提供包括但不限于广告等类目的插件或通过插件提供包括但不限于广告等类目的服务。  
10.2 创作者提供的插件/直播工具或通过插件/直播工具提供的服务，需要取得相关法律法规规定的许可或进行备案的，创作者应当在插件/直播工具提交时进行明确说明并提交相应的合法有效的许可或备案证明。  
10.3 创作者应保证其提供的插件/直播工具的安全性以及稳定性，应符合本规范第2章第8条“技术实现规范”的要求。  
10.4 创作者以及使用者，均不能通过插件/直播工具提供服务的方式，绕开或规避哔哩哔哩平台项目的平台规则。  
10.5 一旦发现创作者和使用者存在违反本条规范的行为，哔哩哔哩有权对其进行限制功能直至下架处理，并有权拒绝再向该主体提供服务。因为插件提供的服务给哔哩哔哩或第三方造成损害的，创作者和使用者应承担赔偿责任。  
10.6 哔哩哔哩对创作者与使用者就开发和使用过程中的合法性、安全性及其性能、双方的开发能力、履约能力，不负担保责任，创作者与使用者因本功能产生的任何纠纷，应由创作者和使用者自行解决，哔哩哔哩不负任何补偿或赔偿责任。  
10.7 插件创作者及使用者为哔哩哔哩用户提供支付服务的，应当遵守法律法规对支付业务的相关要求，不得以任何形式自行从事包括但不限于无证经营支付业务、非法吸收公众存款、集资诈骗等违法违规行为，或为该等行为提供帮助、协助。  
10.8插件/直播工具的功能不得与哔哩哔哩直播官方功能产生重复，若存在功能同质化或重复情形，哔哩哔哩有权要求创作者进行整改，拒不整改的将对该插件/直播工具采取下架等处理措施。  
10.9 插件/直播工具的视觉效果、互动效果等不得与平台礼物效果产生冲突，不得干扰、遮挡平台礼物的正常展示，确保平台礼物效果的完整性和辨识度。  
10.10 插件/直播工具的运营模式、商业变现方式等，不得与哔哩哔哩平台提供的商业模式产生冲突，未经哔哩哔哩授权，不得开展与平台核心商业体系相抵触的商业行为。  
10.11 插件/直播工具内禁止出现任何形式的应用内购买功能，不得设置付费解锁、付费购买道具/服务等相关入口或引导。  
10.12 插件/直播工具的所有能力必须具备实际的用户互动能力，禁止开发无网络连接、脱离开发者服务器、无实际互动价值的工具功能。  
10.13 插件/直播工具禁止提供赌博、抽奖、随机抽取等任何概率类能力，不得通过概率性玩法诱导用户参与或进行相关投入。  
10.14 插件/直播工具禁止存在任何安全风险及侵权问题，对于联动硬件的工具类插件，需提前向哔哩哔哩提交完整的硬件资质、授权证明及安全检测报告，未经审核通过不得开发及上架，严禁开发无合法授权、存在安全隐患的联动硬件工具。  


## 三、互动玩法特别规范

互动玩法是指选择平台项目互动玩法类目并提供互动玩法服务的平台项目。如果您是互动玩法创作者，除需全部遵守以上平台项目的运营规范外，您还应同时遵守以下互动玩法特别规范内容：

### 1. 互动玩法基本规范

1.1 互动玩法的创作，应遵守国家法律法规的各类要求。  
1.2 不得恶意提交互动玩法，不得提交涉嫌抄袭已有互动玩法产品的互动玩法；不得通过简单修改互动玩法美术设计、视觉效果、UI、元素、素材等方式提供多个玩法、内容、功能等基本一致的互动玩法。  
1.3 互动玩法软件著作权有对外授权的，您应向哔哩哔哩提供完整、真实、有效、明确的授权文件，哔哩哔哩将根据授权内容确定唯一发布上线的互动玩法。如授权方允许多个主体同时提交、运营互动玩法的，以先提交者为准。在先提交互动玩法发布上线后，后续相关主体提交相同或近似互动玩法的上线申请均不予接受。因此产生的争议，由您和授权各方协商解决，与哔哩哔哩无关。

### 2. 互动玩法内容规范

**2.1 互动玩法名称**  
- 2.1.1 名称如涉及著名人物、地名、重大历史事件等，不得出现任何歪曲相关情况的内容；
- 2.1.2 不得以政治、宗教、暴力恐怖等争议议题作为名称；
- 2.1.3 名称不得含有或暗示违法、犯罪、暴力、色情、低俗以及违背社会道德准则的内容。

**2.2 互动玩法背景**  
- 2.2.1 背景内容以历史为题材的，不得恶意篡改历史事件、颠覆历史人物形象。

**2.3 互动玩法音乐及音效**  
- 2.3.1 音乐应当符合国家版权管理的法律法规，不得侵犯他人著作权，不得提供非法下载服务；
- 2.3.2 音乐不宜含有过度的惊悚恐怖等不利于身心健康的歌词、画面、乐曲及音响效果。

**2.4 互动玩法场景**
- 2.4.1 不得表现出恐怖、血腥、变态、色情等不利于身心健康的环境或场景；
- 2.4.2 不得渲染血腥恐怖内容，突出、大量制作血迹、残肢、尸体、骷髅等画面。

**2.5 互动玩法娱乐功能**
