## 拓展接口说明

拓展订阅功能的接口为回调信息接口，开发者配置回调地址后，发生的订阅行为都会通过填写的回调地址推送给开发者，开发者根据回调信息中提到的open_id对用户进行提供不同的订阅服务

**<font size=5 color=Red>请注意：本页面的所有接口从触发到开发者返回响应，超时时间为4秒。</font>**
**也就是说当开放平台推送事件后，4秒内未收到开发者回复的响应，则会当作该订单超时，对用户进行退电池操作。**

### 回调接口
** 注意 **
请严格确保回调路径畅通，否则会造成无法提审及主播无法订阅的情况。

注意：
接口加密方式与鉴权和统一鉴权一致，公共参数以及加密方式请参考：[统一鉴权](74eec767-e594-7ddd-6aba-257e8317c05d.md)

| 事件类型 | 含义 | 备注 |
| :- | :- | :- |
| verify_webhooks  | 测试消息 | 除时间戳，其他字段均为空 |
| add_audit_user  |         添加审核用户，需要开通，但无收益 | order_id为空 |
| add_user   |         添加用户，需要开通，有收益 | 字段均有 |

### 订单推送回调地址测试按钮发起请求

**接口描述** ： 接收DLC回调的验证及开通消息。
**通讯方向** ： 开放平台服务器发送至开发者服务器
**接口地址**：开发者自定义，为开发者在DLC页面填写的回调地址
**方法**：POST  
**开放平台发起请求参数**：
```json
{
    // 事件类型
    "event": "verify_webhooks",
    "content":{
        // 主播的open_id，测试请求为空字符
        "open_id":"",
        // 到期时间，测试请求为空字符
        "expire_time":0,
        // dlc唯一id，测试请求为空字符
        "dlc_id":"",
        // 订单id，测试请求为空字符
        "order_id":""
    },
    "timestamp":0// 时间戳
}
```

**开发者收到消息后应该返回以下信息**
注意：
接口加密方式与鉴权和统一鉴权一致，公共参数以及加密方式请参考：[统一鉴权](74eec767-e594-7ddd-6aba-257e8317c05d.md)
**开发者响应**：
```json
{
    "code": 0,
    "message": "ok",
    "data": {
        // 执行状态 非0代表失败
        "action_status": 0
    }
}
```



### 提交审核消息发起订单请求

**接口描述** ： 添加审核用户；开发者提交审核后，将默认发起一条订单推送，推送内容为验收账号的open_id以及相关内容，开发者收到后应该按照用户订阅逻辑进行权限处理，以方便审核人员进行测试与定期回归测试。当审核人员无法使用该DLC则会被视为DLC不可用。
**通讯方向** ： 开放平台服务器发送至开发者服务器
**接口地址**：开发者自定义，为开发者在DLC页面填写的回调地址
**方法**：POST
**开放平台发起请求参数**：
```json
{
    // 事件类型
    "event": "add_audit_user",
    "content":{
        // 审核账号的open_id
        "open_id":"",
        // 到期时间
        "expire_time":0,
        // dlc唯一id
        "dlc_id":"",
        // 订单id，审核用户order_id为空
        "order_id":""
    },
    "timestamp":0// 时间戳
}
```

**开发者收到消息后应该返回以下信息**
注意：
接口加密方式与鉴权和统一鉴权一致，公共参数以及加密方式请参考：[统一鉴权](74eec767-e594-7ddd-6aba-257e8317c05d.md)
**开发者响应**：
```json
{
    "code": 0,
    "message": "ok",
    "data": {
        // 执行状态 非0代表失败
        "action_status": 0
    }
}
```

### 用户订阅完成发起订单请求

**接口描述** ： 用户订阅的时候，开放平台会将订单信息推送给开发者填写的回调服务器，当开发者服务器回复ok的信息后，视为该订阅操作完成，请开发者根据open_id给主播提供对应功能（主播open_id在互动玩法调用start的时候就会返回）。
**通讯方向** ： 开放平台服务器发送至开发者服务器
**接口地址**：开发者自定义，为开发者在DLC页面填写的回调地址
**方法**：POST  
**开放平台发起请求参数**：
```json
{
    // 事件类型
    "event": "add_user",
    "content":{
        // 主播的open_id
        "open_id":"",
        // 到期时间
        "expire_time":0,
        // dlc唯一id
        "dlc_id":"",
        // 订单id
        "order_id":""
    },
    "timestamp":0// 时间戳
}
```

**开发者收到消息后应该返回以下信息**
注意：
接口加密方式与鉴权和统一鉴权一致，公共参数以及加密方式请参考：[统一鉴权](74eec767-e594-7ddd-6aba-257e8317c05d.md)
**开发者响应**：
```json
{
    "code": 0,
```
