# 赛事信息获取

## 1.接入准备

### 1.1 直播创作者服务中心接入
- 请厂商先到直播创作者服务中心入驻，入驻地址：[创作者服务中心](https://open-live.bilibili.com/open-manage)

### 1.2 接入参数申请

厂商在接入赛事数据前，需向对应B站运营人员提供如下申请材料，以获取账号的接入权限。

| 材料名称 | 材料说明 | 示例 |
    |-|-|-|
    |公司名称|厂商的公司名称|上海宽娱数码科技有限公司|
    |联系人|厂商侧联系人姓名|XXXX|
    |联系人手机号码|厂商侧联系人手机号码|186****2867|
    |联系邮箱|厂商侧联系邮箱|XXXX@bilibili.com|
	|access_key_id|在直播创作者服务中心注册后，开发者的access_key_id|EJ8xxxxxxxxxxxxxxxQI|
	
申请信息提交  
    **（1）邮件标题**  
    【直播赛事信息获取】公司名-时间  
    （示例：【直播赛事信息获取】上海宽娱数码科技有限公司-20220715）  
    **（2）邮件收件人**  
	
| 收件 | live-open@bilibili.com；及对接合作运营                                             |
|----|----------------------------------------------------------------------------|
| 抄送 | kuangzilin@bilibili.com;yuanyingqi@bilibili.com|

**请第三方发送邮件后，对接运营同学回复确认并抄送`live-open@bilibili.com`以及`kuangzilin@bilibili.com`，开放平台在收到确认邮件后会进行相关权限配置**

## 获取比赛支持率信息

**请求**：

- 接口描述：权限申请通过后，通过该接口可以获取比赛支持率信息

- 接口地址：/esports/v1/getSupportRate
- 方法：POST  
- 请求参数：

公共头请求和鉴权说明：[签名说明](74eec767-e594-7ddd-6aba-257e8317c05d.md)

| 参数名 | 必选 | 类型 | 描述 |
| :- | :- | :- | :- |
|platform|是|string| 平台，eg. `bilibili`，该参数请与运营确认|
|match_id|是|string| 赛事ID eg. `MSI`|
|match_date|是|string| 赛事日期 eg. `20220525`|
|start_time|是|string| 开赛时间 eg. `14:00`|

**响应**：

```json
{
    "code": 0,
	//错误信息
    "message": "ok",
	//每个请求的唯一码，用于排查
    "request_id":"xxxxxxxx",
    "data": {
        // 比赛支持率信息详情
        "team_ratios": [
            {
                //  队伍名称 eg. RNG
                "vote_team": "",
                //  队伍支持率 eg. 71.25
                "vote_ratio": "",
                //  赛事ID eg. MSI
                "match_id": "",
                //  赛事日期 eg. 20220525
                "match_date": "",
                //  开赛时间 eg. 14:00
                "start_time": ""
            }
        ]
    }
}
```
