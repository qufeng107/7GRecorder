### 用户交互流程

### 查询用户信息接口
说明：查询自定义面板场次和用户（玩家）信息。
地址：/v1/game/getCustomPanelSession
方法：POST
请求参数：

|参数名|必选|类型|描述|
|:--:|:--:|:--:|:--:|
|token|是|string|用户打开面板时生成的临时token，可以从用户访问第三方页面的url后拼接的参数取到|

响应
```json
{
    "code": 0,
    "message": "ok",
    // 请求id
    "request_id": "",
    "data": {
        // 玩家用户openid(用户唯一标识)
        "open_id": "39b8fedb-60a5-4e29-ac75-b16955f7e632",
        // 游戏场次id(与start接口返回的一致)
        "game_id": "",
        // 玩家昵称uname
        "uname": "",
        // 玩家头像
        "uface: "",
		// 当前直播间的粉丝牌等级
		"fans_medal_level": 22,
		// 当前直播间的粉丝牌名称
        "fans_medal_name": "粉丝团",
		// 是否佩戴当前直播间粉丝牌
        "fans_medal_wearing_status": true,
		// 用户大航海等级 1：总督 2：提督 3：舰长
		"guard_level": 3,
    }
}
```

####  错误码

| 错误代码 | 描述           | 备注                                               |
| -------- | -------------- | -------------------------------------------------- |
| 7000     | 不在游戏时间内 | 游戏场次已结束，无法再获取场次的自定义面板信息 （通用code码） |
| 7011     | token错误 |            -           |
