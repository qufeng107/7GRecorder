# 获取已授权用户的union_id信息

Scope: `USER_INFO`   <font color="green">需要申请权限</font>   <font color="red">需要用户授权</font>

## 接口说明

- union_id字段为该用户在您开发者权限下多应用的通用字段，只要开发者不改变，该字段不会变化
- 调用该接口可获取用户的union_id字段

**重要:该接口需要根据业务需求单独申请开通**

## 请求URL

https://live-open.biliapi.com/v2/union_id

## 请求方式

POST

## 请求头

请求增加公共请求头（Request Header），详情请查看 [接口签名说明](74eec767-e594-7ddd-6aba-257e8317c05d.md) 文档

## 请求参数

- url参数

  无

- body参数

| 参数名 |必传|  类型  | 备注       |
| :----: | :----: |:----: | ---------- |
|open_id|是|string|用户的唯一标识|
|app_id|是|int64|应用id|



## 响应参数

- body参数

| 参数名 |  类型  | 备注       |
| :----: | :----: | ---------- |
|union_id|string|用户在同一个开发者下的唯一标识|

- 响应样例

```json
{
    "code": 0,
    "data": {
        "union_id": ""
    },
    "message": "",
    "request_id": "1922228763949772800"
}

```
